# Waypoint

## Course
Application Programming – CCGC-5003

## Project
Waypoint is a trail-finder and trip planner application.

## Week 7 Features

- Distance class
- Trail class
- Itinerary class
- Distance conversion
- Validation
- Trail creation using from_dict()
- Equality comparison
- Total itinerary distance

## How to Run

Open the project in PyCharm.

Run:

test_week7.py

The program will execute all Week 7 tests.
